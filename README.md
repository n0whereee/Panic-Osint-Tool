# Panic OSINT

An OSINT toolkit for username, IP address, phone number, and metadata lookups.

---

## Features

### OSINT Tools
- Username Lookup
- IP Lookup
- Phone Lookup
- Metadata Extractor

---

## Requirements

Python must be installed before using this tool.

**Download Python:**

https://www.python.org/downloads/

During installation, make sure to enable:

- Add Python to PATH

---

## Installation

### Option 1: Automatic Installation

1. Download the project.
2. Extract the archive.
3. Run:

```bat
setup.bat
```

The setup script will:
- Check your Python installation.
- Install the required dependencies.
- Launch the tool automatically.

### Option 2: Manual Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
python main.py
```

---

## Dependencies

- colorama
- requests
- phonenumbers
- Pillow

---

## Usage

After completing the installation, launch the tool using `setup.bat` or run it manually:

```bash
python main.py
```
